# TripWeave AI

Frontend prototype cho đề tài **TripWeave AI – Xây hành trình du lịch theo sở thích**.

## Công nghệ
- HTML semantic
- CSS Flexbox + Grid
- JavaScript DOM / Event
- JSON mock data
- LocalStorage
- Responsive

## Chạy dự án
1. Mở thư mục bằng VS Code.
2. Dùng Live Server để chạy `pages/index.html`.
3. Nếu mở trực tiếp bằng file://, fetch JSON có thể bị trình duyệt chặn; Live Server được khuyến nghị.

## Luồng demo chính
Trang chủ → Khám phá → Trip Planner → AI Itinerary → Chấp nhận/Lưu.

## Các AI feature
1. Itinerary Generator
2. Route Balance Assistant
3. Preference Summarizer

Đây là AI mô phỏng ở Frontend theo yêu cầu đề tài; chưa gọi LLM API thật.
